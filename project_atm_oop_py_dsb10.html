    2. Object-Oriented ATM System with Python

    ด้านล่างนี้จะเป็นโครงสร้างโค้ด OOP ATM ที่ผมได้เขียนขึ้นมาด้วยภาษา Python โดยจะมีการสร้างคลาส Atm ที่มีแอตทริบิวต์และเมธอดต่างๆ เพื่อจำลองการทำงานของ ATM จริงๆ พร้อมบันทึกธุรกรรมทางการเงิน

    Code
    Python 
    
class Atm():    
  
  def __init__(self, name, bank, balance, statement):        
    self.name = name         
    self.bank = bank         
    self.balance = balance   
    self.statement = statement     
  
  def __str__(self):
    text = "You should type (my_atm.Attribute | my_atm.Methods(__, __) to view info." 
    return text 
  
  def withdraw(self, num, hint):
    self.balance -= num  
    self.statement["#Hints"] += [hint]       
    self.statement["$Cash"] += [f"- {num}"]   
    self.statement["Transactions"] += ["Withdraw"] 
    if self.balance < 0:  
      return "You don't have enough money"    
    else:
      text = f"""WithDraw: - {num} | * {hint}"""  
      return text 
  
  def paybills(self, num, hint):
    self.balance -= num  
    self.statement["#Hints"] += [hint]       
    self.statement["$Cash"] += [f"- {num}"]   
    self.statement["Transactions"] += ["Pay Bills"] 
    if self.balance < 0:  
      return "You don't have enough money"    
    else:
      text = f"""Pay Bills: - {num} | * {hint}"""  
      return text 
  
  def deposit(self, num, hint):
    self.balance += num  
    self.statement["#Hints"] += [hint]       
    self.statement["$Cash"] += [f"+ {num}"]   
    self.statement["Transactions"] += ["Pay Bills"] 
    text = f"""Deposit : + {num} | * {hint}""" 
    return text 

my_atm = Atm(
    "Phu",               
    "Bualuang Bank",     
    1000,                
    {                    
        "Transactions": [],
        "$Cash": [],
        "#Hints": [],
    }
)
    ✅ คัดลอกสำเร็จ!

    ถ้าคุณดูโค้ดด้านบนแล้วจะเห็นว่า ผมได้สร้างคลาส Atm เก็บไว้ในตัวแปร my_atm แล้วโดยมีค่าเริ่มต้นของ Attributes เป็น ชื่อผู้ใช้ = "Phu", ธนาคาร = "Bualuang Bank", ยอดเงินคงเหลือ = 1000 ล้าน, และ รายการธุรกรรม = Dict ว่างๆ ซึ่งเราสามารถเรียกใช้ Attributes และ Methods ต่างๆ ของคลาส Atm ได้ผ่านตัวแปร my_atm นี้ครับ

    แน่นอนครับว่าสำหรับโปรเจกต์นี้ ผมจะขออนุญาตนำเสนอวิธีการใช้งาน(เปลี่ยน Transactions) ให้เห็นภาพเป็นหลักนะครับ ส่วนเรื่องของ Coding ผมได้เขียนอธิบายไว้ใน Code Comment ทีละบรรทัดไว้แล้วครับ ใครที่สนใจสามารถเข้าไปดูได้ที่..

    3. Simulate ATM Transactions

    ต่อไปนี้จะเป็นตัวอย่างการใช้งาน(เปลี่ยน Transactions) ของ ATM ที่ผมได้จำลองขึ้นมา โดยจะมีการถอนเงิน, ฝากเงิน, และ จ่ายบิล พร้อมบันทึกธุรกรรมทางการเงิน ซึ่งเราสามารถดูผลลัพธ์ของแต่ละธุรกรรมได้จากการเรียกใช้เมธอดต่างๆ ของคลาส Atm ดังนี้ครับ

    Code
    Python 
    
results = [
    my_atm.withdraw(10, "Medical Expenses"),
    my_atm.deposit(100, "Income per Month"),
    my_atm.paybills(5, "Netflix Rate"),
    my_atm.paybills(5, "Telephone Charges"),
    my_atm.paybills(10, "Food Expenses")
]

for r in results:
  print(r)
    ✅ คัดลอกสำเร็จ!
    • my_atm.withdraw(10, "Medical Expenses") : ถอนเงิน 10 ล้าน ไปจ่ายค่ารักษา
    • my_atm.deposit(100, "Income per Month") : ฝากเงิน 100 ล้าน จากเงินเดือน
    • my_atm.paybills(10, "Netflix Rate") : จ่ายบิล 10 ล้าน จ่ายค่า Netflix

    ทุกๆธุรกรรมจะถูกบันทึกไว้ใน Attributes my_atm.statement ซึ่งเป็น Dict ที่เก็บข้อมูลการทำธุรกรรมทั้งหมด โดยเราจะแปลงข้อมูลใน Dict นี้เป็นตาราง DataFrame ในหัวข้อถัดไปครับ

    4. Transform into a Table

    การแปลงข้อมูลจาก Dict เป็น DataFrame สามารถทำได้ง่ายๆ ด้วยการใช้ไลบรารี Pandas นั่นคือ import pandas as pd ใช้บ่อยมากสำหรับการจัดการข้อมูล

    Code
    Python 
    
import pandas as pd

data = my_atm.statement
df = pd.DataFrame(data)
print(df)
    ✅ คัดลอกสำเร็จ!

    เราจะได้ DataFrame ที่แสดงรายการธุรกรรมทั้งหมดที่เราได้ทำไปก่อนหน้านี้ ซึ่งสามารถนำไปวิเคราะห์หรือแสดงผลต่อได้ตามต้องการ

    5. Verify ATM Balance

    ต่อมาจะเป็นการเช็คยอดเงินคงเหลือในบัญชี ATM ของเราครับ เริ่มต้นเรามีเงินใน ATM 1000 ล้าน ตามหัวข้อที่ 1 Project Introduction ที่กล่าวไปแล้ว จากนั้นเราลองทำธุรกรรมต่างๆ ในหัวที่ 3 Simulate ATM Transactions เราจะมาลองดูจำนวนเงินใน ATM ของเรากันครับ โดยการใช้คำสั่ง

    Code
    Python 
    
summary_cash = [
    my_atm.name,
    my_atm.bank,

]

for i in summary_cash:
  print(i)
    ✅ คัดลอกสำเร็จ!
