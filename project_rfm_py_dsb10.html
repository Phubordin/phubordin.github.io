1.1 ทำความรู้จัก RFM Model

ก่อนจะไปเริ่มกัน ผมอยากให้ทุกคนได้รู้จักกับ RFM Model กันก่อนนะครับ RFM Model เป็นการวิเคราะห์พฤติกรรมการซื้อของลูกค้า โดยแบ่งกลุ่มลูกค้าออกเป็น 11 กลุ่ม

ขอขอบคุณภาพจาก AD ADDICT ศูนย์รวมแห่งคนที่หลงใหลในโฆษณา

โดยจะมีการแบ่งกลุ่มลูกค้าออกเป็น 11 กลุ่มดังนี้

  • Champions (5 ⭐️) : ลูกค้าชั้นยอด ซื้อบ่อยและใช้จ่ายสูง ควรสร้าง Loyalty Program, Upsell, VIP Offer
  • Loyal Customers (5 ⭐️) : ลูกค้าประจำซื้อต่อเนื่อง ทำ CRM, สร้าง Community, Cross-sell
  • Potential Loyalist (4 ⭐️) : ลูกค้าใหม่ที่มีแนวโน้มจะเป็นลูกค้าประจำ กระตุ้นให้ซื้อซ้ำ, Memship Offer
  • Can't Lose Them (4 ⭐️) : ลูกค้าชั้นดีที่หายไป ควรดึงกลับ ให้ข้อเสนอสุดพิเศษ, Persoanal Call
  • New Customers (3 ⭐️) : ลูกค้าใหม่ที่เพิ่งซื้อสินค้า ส่ง Personalized Offer, Welcome Campaign
  • Promising (3 ⭐️) : ลูกค้าใหม่ที่เริ่มซ้ำมากขึ้น ติดตามพฤติกรรม, ทำ Email Retargeting
  • Needs Attention (2 ⭐️) : ลูกค้าที่เริ่มซื้อน้อยลง ส่ง Reminder, โปรโมชัันพิเศษ
  • About to Sleep (2 ⭐️) : ลูกค้ากำลังหายไป ให้ส่วนลดพิเศษ, Exclusive Deal
  • At Risk (2 ⭐️) : ลูกค้าที่เคยซื้อเยอะ แต่หายไป ส่ง Re-Engagement Campaign, Cashback
  • Hibernating (1 ⭐️) : ลูกค้าที่ไม่ได้ซื้อนาน ส่ง Email Reminder, โปรโมชัน Re-activation
  • Lost (1 ⭐️) : ลูกค้าที่หายไปถาวร พยายามดึงกลับด้วย Deep Discount

โดยใช้ 3 ตัวแปรหลักๆ ได้แก่

  • Recency (R) : ลูกค้าซื้อสินค้าล่าสุดเมื่อไร
  • Frequency (F) : ลูกค้าซื้อสินค้าบ่อยแค่ไหน (ในโปรเจกต์นี้ผมใช้ จำนวน Order ที่ลูกค้าสั่งเข้ามา)
  • Monetary (M) : ลูกค้าใช้จ่ายกับสินค้าไปเท่าไร (ในโปรเจกต์นี้ผมใช้ ยอดขายเฉลี่ยต่อเดือนที่ลูกค้ามาซื้อ)

📍 ข้อสังเกต

  • ยิ่งอยู่ทางด้านบน-ขวา (⭐️ สูง) ➤ High Business Impact
  • ยิ่งอยู่ทางด้านล่าง-ซ้าย (⭐️ ต่ำ) ➤ Low Business Impact

Business Impact Level คือ ระดับความสำคัญของกลุ่มลูกค้าต่อรายได้และการเติบโตของธุรกิจ โดยเราพิจารณาจาก Revenue Oppurtunity & Retention Oppurtunity

สรุป Business Impact Level & Actionable Insights

  • High Business Impact Group ➤ 5⭐️ - 4⭐️
    • Champions(สำคัญสุด)
    • Loyal Customers
    • Potential Loyalist
    • Can't Lose Them
    ความสำคัญ: กลุ่มนี้สร้างรายได้หลักและมีแนวโน้มซื้อซ้ำสูงมาก
    Actionable Insight: ส่งแคมเปญเฉพาะกลุ่ม เช่น สิทธิพิเศษ/โปรแกรมสะสมแต้มเพื่อรักษาความสัมพันธ์

  • Medium Business Impact Group ➤ 2⭐️ - 3⭐️
    • New Customers
    • Promising
    • Needs Attention
    • About to Sleep
    ความสำคัญ: มีศักยภาพพัฒนาเป็นลูกค้าประจำหากดูแลอย่างเหมาะสม
    Actionable Insight: ใช้ personalized offer และ nurture campaigns เพื่อกระตุ้นให้กลับมาซื้อซ้ำ

  • Low Business Impact Group ➤ 1⭐️
    • Hibernating
    • Lost
    ความสำคัญ: กลุ่มที่มีแนวโน้มเลิกใช้บริการหรือขาด engagement
    Actionable Insight: ทำ re-engagement campaigns เช่น โปรล้างสต๊อก หรือสอบถาม feedback เพื่อตัดสินใจว่าเก็บหรือปล่อย

def styled_note(text, color="Black", background_color="powderblue", align="center", size="18px"):
    html = f"<div style='text-align:{align}; color:{color}; background-color:{background_color}; font-weight:bold; font-size:{size};'>{text}</div>"
    display(HTML(html))

7.4 Generating RFM Scores for Customer Segmentation

📍 ให้คะแนน RFM สำหรับลูกค้าแต่ละคน โดยการใช้เกณฑ์ที่เราตัดสินใจไว้ในหัวข้อก่อนหน้า

Code
Python 

df_rfm2 = df_rfm1.copy()

def assign_rfm_score(value, percentiles, labels):
    return labels[np.searchsorted(percentiles, value)]

recently_percentiles = np.percentile(df_rfm2["Recently (Days)"], [20, 40, 60, 80])
monetary_percentiles = np.percentile(df_rfm2["Monetary"], [20, 40, 60, 80])

df_rfm2["R_Score"] = df_rfm2["Recently (Days)" # สร้างคอลัมน์ R_Score เก็บค่า Score จากคอลัมน์ Recently (Days)
                            ].apply(lambda x: assign_rfm_score(x, recently_percentiles, [5, 4, 3, 2, 1]))

df_rfm2["F_Score"] = pd.qcut(df_rfm2["Frequency"], q=5, labels=[1, 2, 3, 4, 5])

df_rfm2["M_Score"] = df_rfm2["Monetary" # สร้างคอลัมน์ M_Score เก็บค่า Score จากคอลัมน์ Monetary
                            ].apply(lambda x: assign_rfm_score(x, monetary_percentiles, [1, 2, 3, 4, 5]))

df_rfm2["F_Score"] = df_rfm2["F_Score"].astype(int)

df_rfm2["Y_(F+M)/2"] = (df_rfm2["F_Score"] + df_rfm2["M_Score"]) / 2

8.5 R : Generating RFM Scores for Customer Segmentation

📍 ให้คะแนน RFM สำหรับลูกค้าแต่ละคน โดยการใช้เกณฑ์ที่เราตัดสินใจไว้ในหัวข้อก่อนหน้า

Code
R 

%%R

recently_percentiles <- quantile(df_rfm$`Recently (Days)`, probs = c(0.2, 0.4, 0.6, 0.8), na.rm = TRUE)
monetary_percentiles <- quantile(df_rfm$Monetary, probs = c(0.2, 0.4, 0.6, 0.8), na.rm = TRUE)

assign_r_score <- function(x, breaks) {

    index <- findInterval(x, breaks, rightmost.closed = TRUE)
    return(5 - index)
}

assign_m_score <- function(x, breaks) {
    index <- findInterval(x, breaks, rightmost.closed = TRUE)
    return(index + 1)
}

df_rfm <- df_rfm %>%
    mutate(
    R_Score = sapply(`Recently (Days)`, assign_r_score, breaks = as.numeric(recently_percentiles)),
    F_Score = ntile(Frequency, 5),
    M_Score = sapply(Monetary, assign_m_score, breaks = as.numeric(monetary_percentiles)),
    `Y_(F+M)/2` = (F_Score + M_Score) / 2
    )

df_rfm2 <- copy(df_rfm)

ส่วนที่ 1 : โหลดข้อมูล ➤ สำรวจข้อมูล ➤ ทำความสะอาดข้อมูล :

  • จัดการ NaN ลบคอลัมน์ทิ้ง (วิธีที่ดีที่สุดในการจัดการ NaN ควรไปแก้ไขตอนเก็บข้อมูลต้นทาง)
  • ปรับคอลัมน์ Order Date และ Ship Date ให้เป็นมาตรฐาน ISO
  • กำจัดช่องว่างส่วนเกินโดยใช้ TRIM

ส่วนที่ 2 : วิเคราะห์ข้อมูลด้วย RFM Model ด้วย R และ Python
➤ 📍 เน้นแสดง Insight ของลูกค้า

  • RFM Analysis Using Python :
    • Aggregate ยอดขายเฉลี่ยต่อเดือน, จำนวนครั้งที่ลุกค้าใช้จ่าย และวันล่าสุดที่ลูกค้าซื้อ
    • สำรวจการกระจายตัวด้วย Boxplot และใช้การวัดตำแหน่ง quartile และ Percentile ในการหา R Scode, F Score และ M Score
    • แบ่งกลุ่มลูกค้าออกเป็นทั้งหมด 11 กลุ่ม พร้อม Level Business Impact จากตัว RFM Score
    • คำนวณหาจำนวนลูกค้าแต่ละกลุ่ม
    • ทำการ Plot Tree Map RFM Analysis เพื่อดูการกระจายตัวของกลุ่มลูกค้าแต่ละกลุ่ม
  • RFM Analysis Using Python R : คล้ายกับการวิเคราะห์ด้วย Python เลยแต่ใช้เป็นภาษา R แต่ตัดตัวตอนสำรวจข้อมูลด้วย Boxplot ออกไป จะเน้นเป็นการเขียน R เพื่อวิเคราะห์ RFM เลย

ส่วนที่ 3 (ส่วนเสริม) : วิเคราะห์ข้อมูลยอดขายลูกค้าปี 2017-2020 มีทั้งหมด 9 ตัวอย่าง โดยใช้ Python
➤ 📍 เน้นตั้งคำถาม

  1. Export Customer Data in California (CSV Format)
    ➤ ส่งออกข้อมูลลูกค้าค้าที่อยู่ในรัฐ Califonia

  2. Export Order Data (CSV): Customers in California and Texas, 2017
    ➤ ส่งออกข้อมูลลูกค้าที่อยู่ในรัฐ Califonia และ Texas ในปี 2017

  3. Sales Analysis 2017: Total, Average, and Standard Deviation by Month, Day, and Order
    ➤ คำนวณยอดขายโดยเฉลี่ยต่อวัน ต่อเดือน ต่อออเดอร์ ในปี 2017

  4. Highest Profit Segment in 2018
    ➤ กลุ่มลูกค้าที่สร้างกำไรให้เราสูงสุดใน 2018

  5. Top 5 States with the Lowest Total Sales (15 April – 31 December 2019)
    ➤ รัฐที่มียอดขายต่ำสุด 5 อันดับแรกช่วงวันที่ตั้งแต่ 151 เมษายน ถึึง 31 ธันวาคม 2019

  6. Sales Proportion (%) in West and Central Regions, 2019
    ➤ สัดส่วนยอดขายของภูมิภาคตะวันตกรวมกับภูมิภาคตอนกลาง เทียบกับ ยอดขายรวมทั้งหมด ในปี 2019

  7. Top 10 Products by Order Volume vs. Total Sales (2019–2020)
    ➤ ยอดขายสินค้าโดยเฉลี่ยต่อออเดอร์ 10 อันดับแรกในปี 2019 ถึง 2020

  8. Visual Insights: At Two Plots
    ➤ ดูการกระจายตัวของยอดขาย เทียบกำไร ด้วย Scatter Plot และ ดูการกระจายตัวของจำนวนออเดอร์ เทียบกับยอดขายด้วย Histogram

  9. Summary Exploratory Sales & Customer Analysis (2017-2020)
    ➤ สรุปผลลัพธ์ส่วนที่ 3
