1. Project Introduction

สวัสดีครับ สำหรับโปรเจกต์นี้ผมจะลองทำความรู้จักการเขียนภาษา XML เก็บข้อมูลเมนูอาหารร้านคาเฟ่ง่ายๆ ของเรากันครับ ก่อนอื่นผมจะมาทำความรู้จักหัวข้อเหล่านี้กันก่อน

  • 💭🤔 ภาษา XML คืออะไร สำคัญยังไง ใช้ทำอะไร ?
    (Extensible Markup Language) คือภาษาที่ใช้เก็บข้อมูลในรูปแบบที่ “อ่านง่ายทั้งคนและคอมพิวเตอร์” ทำหน้าที่เก็บ/แลก ข้อมูล, ตั้งค่าโปรแกรม ซึ่งเราสามารถกำหนดเองได้ว่าจะมีแท็กอะไร (เช่น <rice>, <drink> ) เน้นที่ โครงสร้างของข้อมูล มากกว่าการแสดงผล ข้อดีคือมันเป็น มาตรฐานสากล สามารถใช้แลกเปลี่ยนข้อมูลระหว่างระบบต่าง ๆ ได้ เช่น
    • ใบเมนูร้านกาแฟ → XML เก็บเป็นโครงสร้างข้อมูล
    • แอปมือถือ → อ่านไฟล์ XML นี้แล้วเอาไปแสดงผลใน UI
    • ข้อมูลจะเหมือนกัน 100% ไม่ว่าจะแสดงผลที่เว็บ, แอป, หรือส่งไปเครื่องอื่น
    เหมือนเรามี คลังสินค้า (XML) แล้วใครอยากมาซื้อของ (อ่านข้อมูล) ก็เข้ามาหยิบได้เลย

  • 💭🤔 XML ต่างจาก html มากน้อยแค่ไหน ?
    HTML = หน้าตาของเมนู, XML = เนื้อหาของเมนู
    Subject XML HTML
    วัตถุประสงค์ เก็บและขนส่งข้อมูล (Data storage & exchange) แสดงผลข้อมูลบนเว็บ (Presentation)
    แท็ก เราสามารถกำหนดเองได้ เช่น <coffee> <price> มีมาตรฐานตายตัว เช่น <h1> <p> <img>
    โฟกัส ความหมายและโครงสร้างของข้อมูล (What is it?) การแสดงผลและ layout (How it looks?)
    เบราว์เซอร์ เปิดได้ แต่จะแสดงเหมือน plain text เปิดแล้ว render เป็นหน้าเว็บสวยงาม

  • 💭🤔 XML ในโลกของการทำงานมันเอาไปประยุกต์ยังไง ?
    XML ในโลกการทำงานจริง ถูกใช้เยอะมาก แม้จะมี JSON เข้ามาแทนที่ในหลาย ๆ ที่ แต่ XML ก็ยังสำคัญอยู่ โดยเฉพาะในองค์กรใหญ่ ๆ และระบบที่ต้องการมาตรฐานชัดเจน
    เพราะมัน มี Schema / Validation ชัดเจน → ลดโอกาสข้อมูลเพี้ยน
    1. การแลกเปลี่ยนข้อมูลระหว่างระบบ (Data Exchange)
      • XML = มาตรฐานกลาง สำหรับให้ระบบต่าง ๆ คุยกัน เช่น
        - ระบบร้านอาหารส่งใบเสร็จขายรายวันให้บริษัทบัญชี → ส่งเป็นไฟล์ XML
        - เว็บชำระเงิน (Payment Gateway) ส่งผลการจ่ายเงิน → กลับมาเป็น XML
      • 📌 เคสจริง :
        - ธนาคาร, บริษัทประกัน, โรงพยาบาล → ใช้ XML เพื่อแลกข้อมูลกันระหว่างระบบ
        - ภาครัฐ (เช่น ใบกำกับภาษีอิเล็กทรอนิกส์) → ใช้ XML เพราะอ่านได้ทั้งคนและเครื่อง
    2. เก็บโครงสร้างเอกสาร (Structured Documents)
      • XML เหมาะสำหรับเอกสารที่มีโครงสร้างซ้ำๆ และช่วยให้ระบบซอฟต์แวร์เข้าใจ “เนื้อหา + ความสัมพันธ์” ของข้อมูล เช่น
        - ไฟล์ Docx, XLSX, PPTX ของ Microsoft Office จริง ๆ ข้างในคือ XML ทั้งหมด
        - ไฟล์ SVG (ภาพ Vector) ก็เป็น XML
    3. Feed ข้อมูลแบบ Realtime
      • เว็บข่าว, บล็อก, Podcast → ใช้ RSS/Atom Feed ซึ่งเขียนด้วย XML
      • แอปอ่านข่าวสามารถ subscribe feed แล้วดึงบทความล่าสุดได้
      • YouTube ยังมี RSS Feed ที่เป็น XML ให้ดึงรายการวิดีโอออกมา
    4. Config / Setting ของระบบ
      • หลายซอฟต์แวร์ใช้ XML เป็นไฟล์ตั้งค่า (Configuration File) เช่น
        - Android ใช้ XML สำหรับ layout ของ UI และ resource ต่าง ๆ
        - Maven (เครื่องมือ build ของ Java) ใช้ pom.xml กำหนด dependency ของโปรเจกต์
        - โปรแกรม 3D, เกม, เครื่องมือ DevOps หลายตัวใช้ XML เพื่อเก็บพารามิเตอร์
    5. Data Warehouse & BI
      • บางระบบ BI (เช่น SAP, Informatica) export ข้อมูลออกมาเป็น XML
      • 🔥❗️Data Analyst ใช้ Python/R อ่าน XML → แปลงเป็น DataFrame → วิเคราะห์ → สร้างรายงาน
    6. API และ Web Services
      • ก่อนจะมี REST API (JSON)
        → ระบบใช้ SOAP API ซึ่งใช้ XML ในการส่ง request/response
      • ปัจจุบันยังมีบริษัทใหญ่ ๆ (เช่น ระบบการบิน, ธนาคาร) ใช้ SOAP อยู่

2. Cafe Menu Table

ด้านล่างจะเป็นตารางเมนูของเรานะครับ ซึ่งเราจะลองนำมาเขียนใหม่เป็นภาษา XML ดูครับ

ประเภท ชื่อเมนู ราคา ขนาด
Rice American Fried Rice $10 250g
Drink Cocoa $3 22oz
Dessert Chocolate Cake $4 60g
Pasta Spaghetti Kee Mao $10 200g
Bread Croissant $4 60g

ซึ่งจะถูกแปลงเปลี่ยนเป็นโค้ด XML ตามหัวข้อด้านล่างครับ

3. Raw XML Code

เราจะมากำหนด syntax เองเลยในภาษา XML ว่าอันไหนเป็นประเภทอาหารเครื่องดื่มของเรา ดังนี้

  • <rice> → เมนูข้าว
  • <drink> → เมนูเครื่องดื่ม
  • <dessert> → เมนูของหวาน
  • <pasta> → เมนูเส้นพาสต้า
  • <bread> → เมนูขนมปัง
Code
XML 

<cafe>
    <rice>
        <name>American Fried Rice</name>
        <price>$10</price>
        <size>250g</size>
    </rice>
    <drink>
        <name>Cocoa</name>
        <price>$3</price>
        <size>22oz</size>
    </drink>
    <dessert>
        <name>Chocolate Cake</name>
        <price>$4</price>
        <size>60g</size>
    </dessert>
    <pasta>
        <name>Spaghetti Kee Mao</name>
        <price>$10</price>
        <size>200g</size>
    </pasta>
    <bread>
        <name>Croissant</name>
        <price>$4</price>
        <size>60g</size>
    </bread>
</cafe>
