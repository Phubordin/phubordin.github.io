1. Project Introduction

สวัสดีครับสำหรับโปรเจกต์ มีจุดประสงค์ให้เข้าใจและใช้งาน API Public มาจากเว็บไซต์ Air Quality API (Open-Meteo) ข้อมูลที่ผมจะดึงคือ คุณภาพอากาศจากฝุ่น PM2.5, PM10 เป็นรายชั่วโมงย้อนหลัง 90 วัน ที่กรุงเทพมหานคร ประเทศไทย แต่ก่อนอื่นเราจะมาทำความเข้าใจเกี่ยวกับหัวข้อต่อไปนี้ก่อนครับ

  • 💭🤔 API คืออะไร ?
    Application Programming Interface คือ “ช่องทาง/ประตู” ที่เปิดให้โปรแกรมภายนอก (เช่น Python, แอปมือถือ, เว็บอื่น) เข้ามาดึงข้อมูลหรือสั่งงานระบบหนึ่งได้ โดยไม่ต้องรู้รายละเอียดการทำงานข้างในทั้งหมด เช่น ยกตัวอย่าง เราใช้ API ของ Open-Meteo เพื่อ “ขอข้อมูลคุณภาพอากาศ” → เขาจะส่งกลับมาเป็น JSON ที่อ่านง่าย (ตามตัวอย่างนี้เลยครับ)

  • 💭🤔 เว็บ Air Quality API (Open-Meteo) คือใคร ?
    เป็นบริการ ฟรี ที่เปิด API เกี่ยวกับสภาพอากาศและคุณภาพอากาศ ผู้พัฒนาคือ บริษัทสตาร์ทอัพขนาดเล็กจากยุโรป (Germany/Switzerland) ที่อยากให้ข้อมูลอุตุนิยมวิทยาเปิดกว้างสำหรับนักพัฒนา → เน้น non-commercial use ฟรี (งานวิจัย, โปรเจกต์ส่วนตัว, นักเรียน นักศึกษา) ข้อมูลคุณภาพอากาศที่ได้ (pm2.5, pm10 ฯลฯ) นั้น Open-Meteo ไม่ได้วัดเอง แต่ ดึงมาจากแหล่งข้อมูลกลาง/องค์กรวิจัยด้านอากาศ (เช่น CAMS ของยุโรป, ECMWF, NASA) แล้วนำมาคำนวณ forecast/ประมวลผลอีกทีจุดประสงค์ → ให้ทุกคนเข้าถึงข้อมูลอากาศ/มลพิษ ฟรี แบบง่ายๆ ผ่าน API

  • 💭🤔 ความถี่ในการเรียก API (Rate limit) ?
    Open-Meteo Public API → ฟรีแต่มีข้อจำกัดโดยทั่วไป 1,000 requests/วัน ต่อ IP (ใช้ได้เยอะพอสมควรสำหรับโปรเจกต์ส่วนตัว) ถ้าต้องการ มากกว่า (เช่น ดึงแบบ real-time หลายหมื่นครั้ง/วัน, ใช้เชิงพาณิชย์) ต้องจ่ายเงินเพื่อใช้เวอร์ชัน Pro รายชั่วโมง (1 request ต่อชั่วโมง) = แค่ 24 ครั้ง/วัน → สบายมากๆ ไม่เกิน limit แน่นอน

  • 💭🤔 ความหมายของ PM2.5 และ PM10 ?
    PM = Particulate Matter = ฝุ่นละอองแขวนลอยในอากาศ
    ตัวเลข 2.5 และ 10 = ขนาดเส้นผ่านศูนย์กลางของฝุ่น (ไมครอน, µm)
    PM10 = ฝุ่นที่มีเส้นผ่านศูนย์กลาง ≤ 10 µm → ฝุ่นหยาบ (เช่น ฝุ่นดิน, ทราย, ควันไฟ, เขม่ารถ)
    PM2.5 = ฝุ่นเล็กมาก ≤ 2.5 µm → ฝุ่นละเอียด (เช่น ควันบุหรี่, ไอเสียเครื่องยนต์, การเผาไหม้)
    หน่วยที่ใช้ = µg/m³ (ไมโครกรัมต่อหนึ่งลูกบาศก์เมตรของอากาศ)
    ตัวอย่างให้เห็นภาพนะครับ :
    เส้นผมคนเรามีขนาดประมาณ 70 µm
    ฝุ่น PM10 เล็กกว่าผมประมาณ 7 เท่า
    ฝุ่น PM2.5 เล็กกว่าผมประมาณ 30 เท่า → เล็กจนแทรกเข้าปอดและเส้นเลือดได้
    หรือ ฝุ่น PM2.5 = 50 µg/m³ → “ใน 1 ลูกบาศก์เมตร ก็จะมีฝุ่น PM2.5 หนักรวมกัน 50 ไมโครกรัม แขวนลอยอยู่” (ซึ่งเป็นข้อมูลที่เราดึงมาใช้ในโปรเจกต์นี้ครับ)

เมื่อทราบข้อมูล เบื้องต้นไปแล้ว เราจะมาลองเรียกใช้ API ของ Open-Meteo โดยใช้ภาษา Python กันครับ (โปรเจกต์นี้ผมดึงมาอย่างเดียวนะครับ เราอาจนำค่าจตัวเลขไปวิเคราะห์ต่อได้อีก เช่น µg/m³ เท่าไรที่อันตรายแบ่งเป็น Segment สูง, กลาง หรือต่ำได้)

4. Retrieve Data for the Past 90 Days

เริ่มเขียนโค้ดเพื่อดึงข้อมูลคุณภาพอากาศย้อนหลัง 90 วันจาก API ของ Open-Meteo กันครับ

กระบวนการโค้ดหลักๆ คือ

           1️⃣ กำหนด URL ของ API ➡︎ 2️⃣ รับข้อมูล API ➡︎ 3️⃣ จัดการข้อมูลรูปแบบวันที่ ➡︎ 4️⃣ บันทึกลงไฟล์ Excel

Code
Python 

url = (
    "https://air-quality-api.open-meteo.com/v1/air-quality"
    f"?latitude={lat}&longitude={lon}"
    "&hourly=pm10,pm2_5"
    "&past_days=90"
    "&timezone=Asia/Bangkok"
)

api = get(url)
api_json = api.json()
df = pd.DataFrame(api_json["hourly"])

df["time"] = pd.to_datetime(df["time"]).dt.tz_localize("Asia/Bangkok")

cut_time = pd.Timestamp.now(tz="Asia/Bangkok").floor("h") - pd.Timedelta(hours=1)

df = df[df["time"] <= cut_time]

df["time"] = df["time"].dt.tz_localize(None)

df.to_excel(file_name, index=False)
print(f"สร้างไฟล์ใหม่พร้อมข้อมูลย้อนหลัง 90 วันจนถึง {cut_time} ✅ (เวลาย้อนหลัง 1 ชม.เทียบกับเวลา ณ ปัจจุบัน เพื่อการยืนยันข้อมูลที่ถูกต้อง)")

df = pd.read_excel(file_name)
print(df)
✅ คัดลอกสำเร็จ!

จะสังเกตได้ว่าลิงก์ url สามารถกำหนดพารามิเตอร์ต่างๆ ได้ เช่น

  • ?latitude={lat}&longitude={lon} :
    กำหนดพิกัดละติจูด (latitude) และลองจิจูด (longitude) ของสถานที่ที่ต้องการดึงข้อมูล

  • &hourly=pm10,pm2_5 :
    ระบุว่าต้องการข้อมูลคุณภาพอากาศรายชั่วโมง (hourly) สำหรับฝุ่น PM10 และ PM2.5

  • &past_days=90 :
    ระบุจำนวนวันที่ต้องการดึงข้อมูลย้อนหลัง (ในที่นี้คือ 90 วัน)

  • timezone=Asia/Bangkok :
    กำหนดโซนเวลาที่ต้องการใช้ (ในที่นี้คือ Asia/Bangkok)

เราก็จะได้ข้อมูลคุณภาพอากาศฝุ่น PM10 และ PM2.5 รายชั่วโมงย้อนหลัง 90 วัน ที่กรุงเทพมหานคร ประเทศไทยเป็นที่เรียบร้อยแล้วครับ เราสามารถนำข้อมูลนี้ไปวิเคราะห์ต่อยอดได้อีก เช่น (คุณภาพ อากาศดี/ปานกลาง/แย่ ควรมีค่าไมโครกรัมต่อ ลูกบาศก์เมตร เท่าไรกันแน่ เป็นต้น) เรื่องของ Coding ผมได้เขียนอธิบายไว้ใน Code Comment ทีละบรรทัดไว้แล้วครับ ใครที่สนใจสามารถเข้าไปดูได้ที่..
