    1. Filter & Sort Dynamic

    สวัสดีครับ สำหรับตัวอย่างนี้เรามา สำรวจ และจัดการข้อมูลของพนักงานบริษัทแห่งหนึ่ง แบบ Dynamic เพื่อที่จะได้นำไปสรุปข้อมูลเบื้องต้นหรือติดตามงานบางอย่างฉบับฉับไว ตามรูปกันเลยค้าบ !

    Formula
    Google Sheets 
    
                                    =IFERROR(SORT(FILTER(EMPLOYEE, (GENDER = B2) * (PERFORMANCE = B3)), 5, Not(D2)),"NO DATA")
    ✅ คัดลอกสำเร็จ!

    📌 ที่อยู่ Google Sheets : 1. Filter & Sort Dynamic

    📌 อธิบายสูตร : Github

    1. FILTER(EMPLOYEE, (GENDER = B2) * (PERFORMANCE = B3))
      • ผมตั้งชื่อ range ต่างๆที่มีชื่อว่า EMPLOYEE(Table), GENDER(Column), PERFORMANCE(Column) เพื่อง่ายต่อการเลือกช่วง cell มาใช้ ผมจึงเลือกช่วง EMPLOYEE โดยที่เพศ คือ cell B2 ที่ Dynamic และ(*) ผลการปฏิบัติงาน คือ cell B3 ที่ Dynamic ผลลัพธืจึงถูก Filter ออกมา หลังจากนั้น..
    2. SORT(FILTER(..ข้อ 1), 5, Not(D2))
      • ผมตั้งชื่อ range ผมเรียงลำดับ Salary จากมากไปน้อย โดยที่ Salary อยู่คอลัมน์ที่ 5 และ Default ของการ Sort ที่จะเรียงจากน้อยไปมากได้ก็ต่อเมื่อมีค่า TRUE ในอาร์กิวเมนต์ที่ 3 ของ Sort ดังนั้น ผมจึงเลือกคอลัมน์ Salary และเรียงลำดับตาม cell D2 เป็น Checkbox เพื่อให้มีความ Dynamic เมื่อ users ติ้ก D2 = True ซึ่งมันจะเรียงจากน้อยไปมาก ดังนั้นผมจึงใช้ NOT(D2) เพื่อบังคับให้การติ้กของ users นั้นเรียง Salary จากมากไปน้อยโดยอัตโนมัติ
    3. IFERROR(..ข้อ 2,"NO DATA")
      • ถ้าหาก Formula ข้อ 1 หรือ 2 ส่งผลลัพธ์ Error จะให้แสดง NO DATA แต่แน่นอนว่าในตาราง EMPLOYEE จะต้องมีการ filter ที่ไม่ match กัน นั้นหมายความว่าไม่มีค่า filter ที่ต้องการดังนั้นผลลัพธ์จึงแสดง NO DATA นั่นเอง !

    📌 สรุปผลลัพธ์: Filter & Sort Dynamic

    จากตัวอย่างข้างต้น ผมได้อธิบายถึงการกรองข้อมูลของพนักงานที่มีเพศตามกำหนด และมีผลการปฎิบัติงานตามกำหนด โดยที่เรียงลำดับจากเงินเดือนตามเงื่อนไขที่ users ต้องการ ซึ่งผมใช้ Formula ต่างๆ เช่น Filter, Sort, IFERROR ในการจัดการข้อมูลให้มีความ Dynamic มากขึ้น สำหรับตัวอย่างต่อไปจะเป็นการใช้ HCF (Highlight Conditional Formatting) ไปดูกันเลยค้่าบ !

    2. Conditional Formatting: Highlight Row

    HCF คือการกำหนด Format cell ใน SpeadSheets ตามเงื่อนไขที่เรากำหนด ซึ่งมีประโยชน์มากต่อการทำงานเพื่อให้ Audience หรือ users สามารถเห็นข้อมูลที่สำคัญได้ง่ายขึ้น ผมมีตัวอย่างให้ลองดู 4 ตัวอย่าง ดังนี้ครับ

    2.1 Highlight Data Point เฉพาะ Perfomance ที่ Users กรองข้อมูล

    📌 ที่อยู่ Google Sheets : 2. Conditional Formatting: Highlight Row แถวที่ 1 - แถวที่ 26

    Formula
    Google Sheets 
    
                    =$G2=$H$1
    ✅ คัดลอกสำเร็จ!

    📌 อธิบายสูตร : Github

    ก่อนอื่น Set Range ที่ต้องการ HCF ก่อนนะครับ นั่นคือ (A2:G26) ตามรูป =$G2=$H$1 ใช้เพื่อตรวจสอบว่า ค่าของแต่ละเซลล์ในคอลัมน์ G ตรงกับค่าที่อยู่ในเซลล์ H1 หรือไม่ (H1 คือ Dropdown List ของคอลัมน์ G) ถ้าตรงกัน HCF จะทำงานโดยการ Highlight ทั้ง data point(สีเขียว)

    เพื่อให้เข้าใจชัดเจนมากยิ่งขึ้น ผมขอแบ่งเป็น 2 ส่วนเพื่อใช้อธิบายสูตร =$G2=$H$1 ดังนี้

    1. $G2 ไล่เช็คคอลัมน์ G เท่านั้น โดยการไล่ไปที่ละแถวเป็น G1, G2, G3, .., G26 ถ้าแต่ละค่าของ G1, G2, G3, .., G26 matching กับ $H$1 ตามข้อ 2..
    2. $H$1 ก็คือ Dropdown List ที่ค่าภายในคือค่ามาจากคอลัมน์ G ไล่เช็คทุก cell ที่อยู่ในเฉพาะคอลัมน์ G สำหรับแถวที่อยู่ในช่วงแถวที่ 1 - แถวที่ 26 ในคอลัมน์ถ้าหากเจอค่าที่ตรงกับค่าเฉพาะใน $H$1 ให้ Highlight เฉพาะ data point นั้นๆ

    3. Dynamic Query

    Dynamic Query คือการใช้งานฟังก์ชัน Query รวมกับ Dropdown List เพื่อให้ users สามารถกรองข้อมูลได้ตามที่ต้องการ ดังตัวอย่างต่อไปนี้

    Formula
    Google Sheets 
    
=QUERY( EMPLOYEE1, 
"select * where " & 
IF(B2="All","1=1","N='" & B2 & "'") & 
"And " & IF(B3="all","1=1","O = '" & B3 & "'")  &
"And " & IF(B4="All","1=1","L <= date'"& Text(B4,"yyyy-mm-dd") & "'"))
    ✅ คัดลอกสำเร็จ!

    📌 ที่อยู่ Google Sheets : 3. Dynamic Query

    📌 อธิบายสูตร : Github

    • EMPLOYEE1 แทนด้วยช่วงข้อมูล ตามรูปครับ
    • B2 แทนด้วย Dropdown List Gender ที่อยู่ในช่วง EMPLOYEE1
    • B3 แทนด้วย Dropdown List Performance ที่อยู่ในช่วง EMPLOYEE1
    • B4 แทนด้วย Dropdown List Hiredate ที่อยู่ในช่วง EMPLOYEE1

    จากนั้นผมขออนุญาตอธิบายโดยแบ่งเป็น 7 ส่วน (โปรดอ่านตามลำดับ) โดยที่ส่วนที่ 2 - 7 คือ text สังเกตได้จาก " ดังนั้นตอนท้ายจะถูกนำมาเชื่อมกันด้วย & เพื่อให้ชัดเจนยิ่งขึ้นผมขออธิบาย ดังต่อไปนี้

    1. QUERY(EMPLOYEE1, "your query text")

      QUERY() ใช้คล้ายๆกับภาษา SQL ซึ่งมันไว้ใช้กับการจัดการฐานข้อมูล เช่น select, where, order by, groupby etc. โดยที่จะรับค่าพารามิเตอร์อยู่ 2 ตัวหลักๆ ตามตัวอย่างผมจะใช้สูตร QUERY(EMPLOYEE1, "your query text") ที่ซึ่งค่าแต่ละค่าแทนด้วย EMPLOYEE1 ช่วงของข้อมูลตามรูป และ your query text การเขียน query ของเราเพื่อดึงข้อมูล ซึ่งจะเริ่มเขียนอธิบายตั้งแต่ (ข้อ 2 - ข้อ 7)

    2. "select * where " &

      เลือกทุกคอลัมน์ในช่วง EMPLOYEE1 โดยที่จะเขียนเงื่อนไขต่อจาก where ตั้งแต่ข้อ 3 ถึง 7 เลย

    3. IF(B2="All","1=1","N='" & B2 & "'") &

      สูตร IF(เงื่อนไข,1,0) คือ ถ้าเงื่อนไขเป็นจริงจะแสดงผลลัพธ์ 1 ถ้าไม่จริงจะแสดงผลลัพธ์ 0 ดังนั้น

      • ถ้า users เลือก Dropdown List เป็น All จะแสดงผล 1=1 ซึ่ง 1=1 จะคืนค่าความจริงจะทำให้ คำสั่ง "select * where 1=1" แสดงอัติโนมัติ
      • ถ้า users เลือก Dropdown List ไม่เป็น All จะแสดงผล "N='" & B2 & "'"

      2. จะคืนค่าว่าวันนี้วันที่เท่าไร เช่น 2026-01-01 เป็นต้น

      3. จะคืนค่าผลต่างของวันเป็น ปี เดือน หรือวัน หรือาจจะเป็น กี่ปี-กี่เดือน-กี่วัน ก็ได้ ซึ่งจะรับค่า parameter อยู่ 3 ตัวหลักๆ ยกตัวอย่าง 3 แบบ

      • =DATEDIF("2025-01-01", "2026-01-01", "D")

        • ตัวเเรกที่รับค่า คือตัวที่เราจะนำไปลบ ตัวที่สองคือตัวตั้ง "D" นับจำนวนวัน

      • กี่เดือน? =DATEDIF("2000-04-19","2030-07-03","YM") ผลลัพธ์ที่ได้คือ 2

      • กี่วัน? =DATEDIF("2000-04-19","2030-07-03","Y") ผลลัพธ์ที่ได้คือ 14

        • พนักงานคนนี้อายุ 30 ปี 2 เดือน 14 วัน เป็นต้น

        จริงๆมี "YD" อีก คือเราไม่สนใจเดือนเราสนใจแค่ว่า กี่ปี? กี่วัน?

        เพราะ 19 เม.ย ห่างจาก 03 ก.ค. อยู่ 72 วันนั่นเอง

    • ตามด้วย [A-z]+. ดึงค่าตัวอักษรภาษาอังกฤษตัวพิมพ์ใหญ่หรือเล็ก A-z มากี่ตัวก็ได้ ตามด้วยตัวอะไรก็ได้ทั้งหมดเลย (ตัวอักษร, ตัวเลข, ตัวอักขระพิเศษ, white space ยกเว้นการขึ้นบรรทัดใหม่ภายใน cell) 1 ตัว

      • (ผลลัพธ์คือ 31 Oct ) อยากให้โชว์ผลลัพธ์ต้องใส่วงเล็บปิดในสูตรเช่น (\d{2}.[A-z]+.)
